# Читалка (ReaderLite)

Android-приложение для чтения статей без мусора. Вставляешь ссылку или отправляешь страницу через «Поделиться» — и видишь только заголовок, текст и картинки. Баннеры, рекламу, всплывающие окна, скрипты и трекеры приложение отбрасывает.

## Что умеет

- Открывает статью по ссылке или из системного «Поделиться» (в том числе из браузера).
- Извлекает заголовки, абзацы, цитаты, списки, блоки кода и картинки.
- Отбрасывает `script`, `style`, формы, навигацию, шапки и подвалы, диалоговые окна, элементы с рекламными и баннерными классами.
- **История** — все открытые статьи, сортировка по последнему открытию.
- **Сохранённые** — статьи, отложенные для чтения. Сохранённые статьи открываются офлайн.
- **Экспорт** — текст статьи через системное «Поделиться».
- **Настройки** — тёмная тема (по умолчанию включена), размер шрифта, шрифт с засечками.
- Всё хранится локально в Room. Облака и синхронизации нет.

## Стек

- Kotlin, Jetpack Compose, Material 3
- jsoup — разбор HTML и выделение статьи
- Room — локальная база (история, сохранённые статьи, блоки статьи в JSON)
- Coil — загрузка картинок

## Сборка

Нужны Android Studio (или JDK 17 и Android SDK 35) и доступ к Google Maven.

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для Gradle wrapper выполни один раз `gradle wrapper` в корне проекта, он создаст `gradlew`.

## Релиз

Workflow `.github/workflows/release.yml` собирает APK и публикует его как GitHub release. Запускается при пуше тега вида `v0.1.0` или вручную через Actions.

## Ограничения первой версии

- Извлечение статьи эвристическое. На сложной вёрстке могут остаться лишние куски или пропасть фрагменты. Мусор, который попал в статью, лечится добавлением маркеров в `JUNK_TOKENS` в `ArticleExtractor.kt`.
- Страницы, которые строятся JavaScript-ом после загрузки, jsoup не видит. Такие статьи не откроются.
- Картинки загружаются из сети при открытии. Сохранённые статьи хранят ссылки на картинки, а не сами файлы, поэтому офлайн картинки могут не показаться.
